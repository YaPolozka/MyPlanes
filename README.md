# MyPlanes

Android-приложение для планирования задач по **матрице Эйзенхауэра**. Каждая задача попадает в один из четырёх разделов в зависимости от срочности и важности, а приложение напоминает о ней уведомлением в нужное время.

## Возможности

- Четыре раздела: **срочно и важно**, **срочно, не важно**, **не срочно, важно**, **не срочно, не важно**
- Создание задачи: название, описание, раздел, дедлайн, дата и время уведомления
- Отметка «выполнено» галочкой и её снятие
- Удаление задачи: задача остаётся в своём разделе с пометкой «Удалена»
- Уведомление на телефон в выбранное время (для выполненных и удалённых задач не приходит)
- Просроченные дедлайны подсвечиваются красным
- Автоматическое удаление выполненных и удалённых задач через 7 дней

## Как это работает

- **Разделы.** Кнопка «+» открывает форму с предвыбранным разделом, соответствующим текущей вкладке.
- **Дедлайн.** Хранится как конец выбранного дня: задача считается просроченной только после него.
- **Уведомления.** Ставятся через WorkManager и переживают закрытие приложения и перезагрузку телефона. Перед показом проверяется состояние задачи. Время срабатывания приблизительное: возможна задержка до нескольких минут.
- **Автоочистка.** Через 7 дней после последнего действия (выполнения или удаления) задача удаляется окончательно. Очистка запускается при старте приложения и раз в сутки в фоне.

## Технологии

- Kotlin
- Jetpack Compose и Material 3
- Room (через KSP) для локальной базы данных
- WorkManager для уведомлений и автоочистки
- Navigation Compose
- ViewModel и StateFlow

## Сборка и запуск

Требования: актуальная стабильная версия Android Studio и устройство или эмулятор с Android 8.0 (API 26) и выше.
